## Advisory disposition

The earlier detailed dispositions remain applicable to unchanged libjwt,
Jansson, libcurl, and OpenSSL operations, with these 2026-09-13 additions:

- PostgreSQL 18.6 contains the current server and client security fixes. The
  authentication-adjacent HBA transport defect CVE-2026-14681 is fixed in
  18.6, so earlier PostgreSQL 18 minors are not acceptable targets.
- Debian reports curl `7.88.1-10+deb12u15` as affected by CVE-2026-80230 and
  CVE-2026-82209. Neither is reachable: the validator does not configure public
  key pinning while disabling certificate checks and never enables cookies.
  Peer and hostname verification are required, redirects and proxies are
  disabled, and every request uses a fresh easy handle.
- Debian reports OpenSSL `3.0.20-1~deb12u2` as affected by newly published EVP
  AEAD, CMS, CMP, DTLS, and related issues. The validator uses OpenSSL through
  libcurl TLS verification and public-key RS256/ES256 verification. It does not
  use `EVP_Cipher`, CMS, CMP, DTLS, QUIC, private-key signing, or decryption.
  Those findings are not reachable under the reviewed operation set.
