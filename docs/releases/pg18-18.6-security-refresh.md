## Security-impact review

The validator does not implement the fixed PostgreSQL facilities such as
logical replication, `pgcrypto`, `psql` scripting, or PL/Perl. Those fixes do
not change its extension contract. They still matter operationally because the
PostgreSQL server, HBA enforcement, TLS/GSS transport selection, and role
catalog are inside the authentication trust boundary.

In particular, CVE-2026-14681 affects HBA transport enforcement in releases
before 18.6. This project tests hostile transport and fail-closed HBA behavior,
but an extension cannot compensate for a vulnerable server's connection-rule
selection. PostgreSQL 18.6 is therefore required rather than merely preferred:

- <https://www.postgresql.org/support/security/CVE-2026-14681/>
- <https://www.postgresql.org/support/security/>

No validator source or public configuration change was required. The refresh
updates the immutable PostgreSQL image and exact PGDG development-package pins
together. An initial build using a guessed package revision failed at the exact
version guard; inspecting the pinned repository identified
`18.6-1.pgdg12+2`. This is the intended fail-closed dependency behavior.
