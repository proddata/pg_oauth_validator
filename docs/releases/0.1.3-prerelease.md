# 0.1.3 prerelease preparation

Status: candidate preparation only; unsigned and unpublished. The final release
source revision and CI run identifiers must be recorded after validation. Do not
promote an earlier PR merge candidate as a build of the final release revision.

This prerelease adds experimental PostgreSQL 18 RPM packaging for Fedora 43,
Fedora 44 and Rocky Linux 10 on x86-64 and ARM64. The release rehearsal uses
locked complete builders, two fresh native builds per target, byte comparison
of RPM/SRPM bundles, and real retained 0.1.2 -> 0.1.3 -> 0.1.2 package tests.
The 0.1.2 baseline is rebuilt from its pinned source release; no RPM was
published with that version. It is not a previously published RPM rollback
promise. PostgreSQL 19 archive packages remain preview artifacts.

## Known limitations accepted for this prerelease

- Production readiness is not claimed. Dependency/security and license review
  completion is reported by the deployment owner; final candidate validation
  and release signing/approval remain required.
- Rocky OpenSSL remains affected by CVE-2026-35189. The owner accepts the
  residual availability risk for the intended deployment's controlled
  discovery/JWKS endpoints and certificates. This is not a package fix or a
  blanket exception for other deployments/providers. Review expires on
  2026-11-22 or earlier on a threat-model change; see
  [the recorded exception](../rpm-dependency-review.md#controlled-endpoint-exception-cve-2026-35189)
  and [follow-up #28](https://github.com/proddata/pg_oauth_validator/issues/28).
- No additional durable artifact storage is arranged. RPM builders and evidence
  use existing 90-day CI retention, while PostgreSQL release-candidate archives
  use 14-day CI retention. Builder expiry is based on the original capture;
  running a new candidate does not refresh it. Exact reproduction and rollback
  may become unavailable after expiry. No online replacement is permitted.
- SELinux-enforcing evidence covers Fedora 44 x86-64 only; equivalent enforcing
  coverage on the other five RPM targets is not claimed.
- Pinned Keycloak interoperability is separate from claims of live
  interoperability with Auth0, Okta, Entra, WorkOS or other providers.

## Installation and rollback

Use only the package built for the exact PostgreSQL major and supported
platform/architecture. Retain the actual previous package and protected
configuration before upgrading; stop PostgreSQL before restoring the previous
package/configuration pair. Follow [the RPM upgrade/rollback procedure](../rpm-platforms.md#upgrade-and-rollback-rehearsal).
Do not rely on expired CI artifacts for recovery. Package tests do not approve
an individual production installation.
